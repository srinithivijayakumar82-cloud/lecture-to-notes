# Lecture to Notes

An AI-powered tool that converts lecture transcripts into structured, easy-to-review notes.

## Tech Stack
- Frontend: React + Vite
- Backend: FastAPI (Python)
- AI: Groq API (Llama 3.3 70B)

## Features
- Paste any lecture transcript
- Get AI-generated structured notes instantly
- Organized by title, summary, key points, and topics
- Clean, readable format for easy revision
